# Telegram-бот посещаемости — исправленная версия для FadeHost

## FadeHost settings
- **Branch:** `main`
- **Build command:** `pip install -r requirements.txt`
- **Start command:** `python bot.py`

Все Python-файлы (`bot.py`, `config.py`, `database.py`, `keyboards.py`, `sheets.py`, `utils.py`, `import_students.py`) должны находиться в корне репозитория рядом с `requirements.txt`.

## Переменные окружения
В настройках проекта FadeHost добавьте:
- `BOT_TOKEN` — новый токен бота от @BotFather
- `ADMIN_IDS` — Telegram ID старосты (число; если несколько, разделите запятыми)
- `TIMEZONE` — например `Asia/Yekaterinburg`
- `DATABASE_PATH` — `data/attendance.sqlite3`
- `ATTENDANCE_WINDOW_MINUTES` — `30`
- `REMINDER_HOUR` — во сколько присылать напоминания о домашках и контрольных (по умолчанию `9`)
- `DEPUTY_IDS` — необязательно: ID заместителей через запятую (могут только открывать отметку)

Google Sheets необязателен. Для включения синхронизации задайте `GOOGLE_SHEETS_ID` и `GOOGLE_SERVICE_ACCOUNT_JSON` (всё содержимое JSON-ключа сервисного аккаунта; файл на сервере не нужен). Таблицу нужно предоставить в доступ на редактирование email сервисного аккаунта (`client_email` из ключа). Вкладки Students, Lessons и Attendance бот создаст сам. Если эти настройки не заданы, бот работает с SQLite без синхронизации.

## Первоначальная настройка
1. Вставьте файлы в корень GitHub-репозитория, заменив старые версии.
2. Проверьте, что `requirements.txt` тоже в корне.
3. В FadeHost проверьте команды сборки/запуска выше и переменные окружения.
4. Сделайте Commit changes в GitHub. FadeHost должен выполнить новый deploy.
5. В Telegram отправьте боту `/start`. Для проверки ID используйте `/id`.
6. Студенты регистрируются сами: каждый отправляет боту `/start`, вводит ФИО и группу, а староста получает сообщение с кнопками «Подтвердить / Отклонить» (также есть раздел «Заявки на регистрацию» в `/admin`). Заявка самого старосты подтверждается автоматически.
7. Импорт из CSV (`python import_students.py students.csv`) необязателен и нужен только если есть доступ к консоли.

## Команды старосты
- `/admin` — панель; `/export` — CSV с посещаемостью; `/reset` — сброс данных
- `/setschedule` — загрузить расписание текстом (даты `24.10 суббота`, ниже пары); при изменении уже сохранённого дня бот предложит уведомить студентов
- `/addhw` — добавить домашку (предмет, дедлайн, задание); напоминания за 7, 3, 2 и 1 день
- `/addtest` — добавить контрольную (предмет, дата и время, аудитория); напоминания за 7 дней, за 1 день и утром в день контрольной
- `/events` — список домашек и контрольных: изменить, перенести, удалить (с уведомлением студентов или без)
- `/students` — список студентов по группам; нажатие на имя удаляет студента (вместе с его отметками, после подтверждения)

## Команды студентов
`/schedule`, `/today`, `/tomorrow`, `/hw [предмет]`, `/tests` — или кнопки внизу чата. Под домашкой есть кнопка «Сделано»: после неё напоминания по этому заданию прекращаются.

**Важно:** SQLite-файл на хостинге должен сохраняться между перезапусками, иначе записи могут потеряться. Если платформа не предоставляет постоянный диск, потребуется внешняя база данных.

Не публикуйте токен бота или JSON-ключ Google в репозитории. Если токен уже попадал на скриншоты, отзовите его через @BotFather и сохраните новый только в переменных окружения FadeHost.
